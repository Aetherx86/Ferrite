# Ferrite

전국 통합 도시철도 및 대중교통 네비게이션 플랫폼 (Kotlin Multiplatform)

전국 도시철도의 다음 열차 도착 정보, 직관적인 노선도, 최적 길찾기, 걷기 경로, 공항 운항 전광판, 실시간 버스 도착 정보를 하나로 통합한 애플리케이션입니다. Kotlin Multiplatform 기반으로 구축되어 Android, iOS, 웹(WebAssembly)에서 동일한 단일 코드로 구동됩니다.

[English Documentation](README.md) • [웹 브라우저에서 바로 체험하기](https://aetherx86.github.io/ferrite/) • [최신 Android APK 다운로드](https://github.com/Aetherx86/Ferrite/releases/latest)

## 핵심 기능

| 기능 | 세부 설명 |
| --- | --- |
| 역 전광판 | 남은 시간을 대형 디스플레이로 제공하며 실시간 이동 열차와 칸별 혼잡도를 함께 표시합니다. 열차 도착 시 노선 고유 색상이 화면에 퍼지며 접근음, 도착 벨, 출입문 닫힘 경고음이 울립니다. 가로 및 세로 모드를 모두 완벽하게 지원합니다. |
| 노선도 | 수도권, 부산, 대구, 대전, 광주 전역 943개 역의 직선 노선도를 제공합니다. 확대 배율에 따라 역명이 겹치지 않도록 동적으로 렌더링하며 노선 선택 시 해당 노선만 집중 강조합니다. |
| 벡터 지도 | 시도 및 시군구 경계, 실제 철도 궤도 형상부터 도로, 빌딩, 하천, 공원, 한글 지명까지 앱 내부 엔진이 직접 렌더링하는 순수 벡터 지도입니다. |
| 길찾기 | 네트워크 연결 없이도 최단 시간 및 최소 환승 경로를 오프라인으로 탐색합니다. 각 철도 운영기관이 실측한 환승 보행 거리와 수도권 통합 거리비례 요금제를 정밀 반영합니다. |
| 보행 내비게이션 | 최단 경로, 계단 없는 완만한 경로, 조명이 밝은 대로변 안심 경로를 다각도로 비교 제공합니다. 횡단보도 수, 턴바이턴 안내, 최적 지하철 출구 번호를 안내합니다. |
| 차량 내비게이션 | 일반 승용차, 경차, 전기차, 화물차(차고 및 중량 제한 반영), 이륜차, 자전거 맞춤형 경로를 탐색합니다. 통행료 회피, 도착지 인근 주차장 자동 연계, 택시 예상 요금을 산출합니다. |
| 전기차 특화 | 주행 후 도착 시점의 예상 배터리 잔량을 정밀 계산하며, 충전 필요 시 경로 인근 최적 충전소를 경유지로 자동 제안합니다. |
| 일정 및 여행 | 방문 희망 장소를 날짜별로 등록하면 이동 동선이 최소화되도록 최적 방문 순서를 자동 계산하며 체류 시간, 예산, 메모를 로컬 기기에 안전하게 보관합니다. |

## 플랫폼 아키텍처

| 모듈 | 역할 |
| --- | --- |
| `shared/src/commonMain` | Compose Multiplatform 기반의 모든 UI 화면 및 공통 비즈니스 로직 |
| `shared/src/androidMain`, `iosMain`, `wasmJsMain` | 각 타깃 플랫폼별 네이티브 네트워크, 오디오 신시사이저, GPS 위치 및 저장소 연동 |
| `androidApp`, `iosApp` | 각 플랫폼용 래퍼 셸 애플리케이션 |
| `tools/` | 오픈 데이터 정제, 노선 그래프 추출 및 스키매틱 레이아웃 산출 파이프라인 (Python) |

## 빌드 및 테스트

```bash
# 호스트 단위 테스트 실행
./gradlew :shared:testAndroidHostTest

# WebAssembly 웹 배포 아티팩트 빌드
./gradlew :shared:wasmJsBrowserDistribution
```

## 0.3.0 변경 사항

- 지하철 길찾기가 가장 빠른 경로와, 몇 분 더 걸리는 대신 환승이 적은 경로들을 함께 보여 줍니다. 보여 주는 경로 가운데 시간과 환승 횟수가 모두 더 나은 다른 경로는 없습니다. 가장 빠른 경로보다 20분 또는 그 시간의 절반 이상 더 걸리는 경로는 빼고 보여 줍니다.
- 환승 대기 시간을 일정한 3분 대신, 그 시간대와 요일에 갈아탈 노선이 다니는 평소 간격의 절반으로 계산합니다. 환승마다 걷는 시간과 기다리는 시간을 따로 보여 주고, 하차 알림도 둘 다 셉니다. 평소 운행 시간(05:30부터 다음 날 00:30까지) 밖에 출발하거나 환승하면 화면에 알려 줍니다.
- `여유 있게 환승`을 고르면 승강장 사이를 걷는 시간을 1.5배로 잡고 1분을 더합니다. 기기에 저장됩니다.
- 노선 데이터를 읽을 때 잘못된 구간, 있을 수 없는 운행 시간, 중복된 번호, 읽을 수 없는 색을 빼거나 바꾸고 목록으로 남기므로, 데이터가 손상되어도 앱이 멈추지 않습니다.
- 걷기, 운전, 세계 길찾기 서비스가 보낸 경로 모양이 손상되거나 잘려 있어도, 읽을 수 있는 부분까지 그립니다.

```bash
./gradlew --no-daemon :shared:testAndroidHostTest
./gradlew --no-daemon :shared:wasmJsBrowserDistribution
```
